# Full-Stack Hotel Reservation System

A comprehensive web application designed to manage hotel room bookings, developed as part of a Database Design and Implementation course at NYU.

## Tech Stack
* **Backend:** Python, Flask
* **Frontend:** HTML5, CSS3, Jinja2 Templates
* **Database:** SQLite, SQL
* **Design:** Entity-Relationship Diagram (ERD)

## Core Features
* **Dynamic Filtering:** Users can search for rooms based on price, number of guests, and proximity to specific locations.
* **Database Management:** A fully normalized relational database built with SQLite to handle real-time reservations and customer data.
* **Full-Stack Integration:** Seamless connection between the SQL backend and the Flask frontend using Jinja2.
